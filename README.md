Description: This program is a Shape Management System developed in Java. It allows the user to create, remove, display, translate, and scale different geometric shapes through a console-based menu. The program supports shapes such as Circle, Square, Rectangle, and Triangle, and it can also calculate the area and perimeter of a selected shape.

Required Libraries: java.util.Scanner, java.util.ArrayList

Installation: No external libraries are required. The program can be compiled and run using the Java compiler.

Usage: Compile and run the program starting from the Main class.

Add a shape
Remove a shape by ID
Get information about a shape by ID
Display area and perimeter of a shape
Display all shapes
Translate all shapes
Scale all shapes
Exit the program
